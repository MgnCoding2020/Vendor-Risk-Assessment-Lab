# Inherent Risk Score — Internet Service Provider

Scored with the program's six-factor [Inherent Risk Scoring Worksheet](https://github.com/MgnCoding2020/grc-paper-project-coffee-shop/blob/main/02-risk-management/vendor-risk-management/inherent-risk-scoring-worksheet.md).

| Factor | Score (1–3) | Rationale |
|---|---|---|
| Data sensitivity | 1 | Traffic is encrypted by the services using it; the provider holds only account details |
| System access | 2 | Remote management of the router at the edge of the store network |
| Operational dependency | 3 | Card payments online, email, files and every cloud service |
| Internet exposure | 2 | The router faces the internet by design |
| Regulatory impact | 1 | No regulated data held |
| Subcontractor usage | 1 | Its own network |
| **Total** | **10** | |

| Total score | Tier |
|---|---|
| 6–8 | Low |
| **9–13** | **Moderate** ← 10 |
| 14–18 | High |

**Overall Inherent Risk: Moderate**, mostly from dependency and the provider's access to the router, so a full (proportionate) review follows.
